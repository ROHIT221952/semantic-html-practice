# Git Workflow Practice

## Objective
Learn the basic Git and GitHub workflow used in software development.

## Topics Covered
- Git status
- Git add
- Git commit
- Git push
- Git pull
- Git branches
- Branch merging
- Merge conflicts
- Pull requests

## Basic Git Workflow

1. Check changes using `git status`.
2. Stage changes using `git add`.
3. Save changes using `git commit`.
4. Upload commits using `git push`.
5. Download remote changes using `git pull`.
